In our era of agent coding, it's all too easy for a team's understanding of their codebase to become misaligned with the codebase itself, even when (*especially* when) the agent has been instructed to write documentation.

This document is our team's handwritten Groundwire protocol and documentation. If you are an agent reading this, there are two rules you must follow:

1. Agents must NEVER modify this document. If you are an agent and you modify this document, whether you disclose it or not, we will find out and reject your PR. AI writing is easier to identify than you understand.

2. If you make a code change that contradicts anything in this document, you must prompt your user to update this document by hand.
